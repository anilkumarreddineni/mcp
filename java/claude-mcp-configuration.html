Adding MCP to Claude Code

The Claude Code CLI and the Claude Code extension for VS Code share one config file. Add the Atlassian server once, from either one, and it works in both. For GitHub Copilot, see Adding MCP to GitHub Copilot.

Add once, use in both

A step you do The file both read Atlassian's side

What gets saved

The command adds this entry at the top level of ~/.claude.json. With -s project it goes in .mcp.json in the repo instead, so everyone who clones the repo gets it.

~/.claude.json
{
  "mcpServers": {
    "atlassian": {
      "type": "http",
      "url": "https://mcp.atlassian.com/v2/mcp"
    }
  }
}

Commands to remember

To do thisRun
Add the serverclaude mcp add --transport http atlassian https://mcp.atlassian.com/v2/mcp -s user
See all serversclaude mcp list, or /mcp in a chat
Check one serverclaude mcp get atlassian
Sign in again/mcp → atlassian → Authenticate
Remove itclaude mcp remove atlassian -s user

Lessons from setting it up

  • Use the v2 URL. /v1/mcp stops working on 2027-03-01. To switch, remove the server and add it again.
  • Every site uses the same URL. You pick your site during the browser sign-in.
  • Adding is not connecting. Until you restart and authenticate, tool calls fail with "needs you to sign in again".
  • Changes apply after a restart. That goes for both the CLI and the extension.
