Adding MCP to GitHub Copilot

Copilot CLI and Copilot in VS Code keep separate config files, so you add the Atlassian server in each one. Claude Code works differently: its CLI and VS Code extension share one file. See Adding MCP to Claude Code.

Add it in each one

A step you do Where it's saved Atlassian's side

The two files

The entries look the same apart from the top-level key: mcpServers in Copilot CLI and servers in VS Code.

Copilot CLI

~/.copilot/mcp-config.json
{
  "mcpServers": {
    "atlassian": {
      "type": "http",
      "url": "https://mcp.atlassian.com/v2/mcp"
    }
  }
}

Copilot in VS Code

.vscode/mcp.json
{
  "servers": {
    "atlassian": {
      "type": "http",
      "url": "https://mcp.atlassian.com/v2/mcp"
    }
  }
}

Keep in mind

  • Copilot needs its own setup. Copilot doesn't read Claude Code's ~/.claude.json, and Claude Code doesn't read Copilot's files.
  • VS Code uses MCP tools only in Agent mode. Switch Copilot Chat to Agent mode to see the Atlassian tools.
  • Workspace or Global. Workspace saves .vscode/mcp.json, which goes into git with the repo. Global keeps it to you.
  • Use the same v2 URL. As with Claude Code, use https://mcp.atlassian.com/v2/mcp and pick your site at sign-in.
